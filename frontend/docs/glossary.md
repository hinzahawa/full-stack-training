# Glossary

## Profile

The personal identity block containing name, role, location, contact links, and portrait.

## Experience

The work-history timeline shown on the page and summarized in the downloadable resume.

## Stack

The grouped technologies used by the resume owner, split into frontend, backend, and DevOps.

## Resume PDF

The downloadable document served from `/resume.pdf` by a Next.js Route Handler.

## Portrait Asset

The visual profile image shown in the left panel. The current asset is `public/profile.svg`.
